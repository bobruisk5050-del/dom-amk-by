# Подробная инструкция: Настройка Telegram, замена фотографий и перенос на хостинг

---

## 1. Где лежат фотографии и как заменить их на свои настоящие фото со склада

Все изображения сайта теперь лежат в специальной папке **`public/images/`**. 
Они имеют понятные простые имена:

| Имя файла | За что отвечает | Рекомендация |
| :--- | :--- | :--- |
| **`osb_boards.jpg`** | Фото стопок OSB-3 плит на складе | Сфотографируйте поддоны с ОСБ на ул. Орджоникидзе |
| **`roofing_tiles.jpg`** | Металлочерепица / Ондулин | Фото стендов с образцами или стопок листов |
| **`profile_pipes.jpg`** | Профильная труба на стеллажах | Фото металлобазы или стеллажей с трубами |
| **`facade_amk.jpg`** | Фасадная система АМК | Фото образцов кирпича на сетке или готового дома |
| **`hero_depot.jpg`** | Фоновая картинка на самом первом экране | Широкий общий вид склада |

### Как заменить фото:
* **Самый простой способ:** Возьмите ваше реальное фото, переименуйте его точно так же (например, `osb_boards.jpg`) и просто скопируйте в папку `public/images/`, заменив старый файл. Сайт моментально подхватит новое фото!
* Если хотите добавить новые фото с другими названиями: откройте файл `src/data/catalog.ts` и укажите там новый путь, например: `image: '/images/moyo_foto.jpg'`.

## 2. Как подключить Telegram-бота для получения заявок

Когда посетитель оставляет номер телефона на сайте, бот в ту же секунду присылает сообщение владельцу в Telegram.

### Шаг 1: Создание бота (1 минута)
1. Откройте Telegram и в поиске найдите **`@BotFather`** (с синей официальной галочкой).
2. Нажмите **Start** и отправьте команду: `/newbot`.
3. Назовите бота, например: `Склад Дома и Кровли Бобруйск`.
4. Задайте юзернейм на английском, оканчивающийся на `bot` (например: `dom_amk_bobruisk_bot`).
5. `@BotFather` пришлет вам секретный **HTTP API Token** (длинная строчка вида `7849302194:AAHv9yT...`). Скопируйте её.

### Шаг 2: Узнать свой цифровой Chat ID
1. В Telegram найдите бота **`@userinfobot`** или **`@getmyid_bot`** и нажмите **Start**.
2. Бот сразу напишет ваш цифровой `Id` (например: `987654321`). Скопируйте эти цифры.
*(Если хотите получать заявки в общий чат с коллегами: создайте группу в Telegram, добавьте туда созданного бота и узнайте ID группы).*

### Шаг 3: Куда вставить токен и Chat ID
Откройте файл конфигурации **`.env`** в корне проекта (или укажите прямо в файле `src/services/telegram.ts` в строках 18-19):
```env
VITE_TELEGRAM_BOT_TOKEN="7849302194:AAHv9yT..."
VITE_TELEGRAM_CHAT_ID="987654321"
```
После этого запустите сборку (`npm run build`). Теперь любая заявка с сайта летит напрямую в Telegram владельца!

## 3. Где находится иконка во вкладке браузера (вместо глобуса)
* Иконка создана и находится в файле **`public/favicon.svg`**.
* Теперь во вкладке браузера вместо безликого серого глобуса отображается стильный темный значок с золотистой крышей дома («Дома и кровли»).

## 4. Пошаговый план переноса сайта на хостинг твоего знакомого

У твоего знакомого сайт `dom-amk.by` уже работает на каком-то хостинге (например, Hoster.by, ActiveCloud, Beget, cPanel или ISPmanager). 

1. **Создайте свежую сборку сайта:**
   В терминале проекта выполняется команда:
   ```bash
   npm run build
   ```
   В результате создается папка **`dist`**. Внутри неё находятся:
   - `index.html` (главная страница сайта)
   - `favicon.svg` (иконка во вкладку)
   - `.htaccess` (правила перенаправления со старых 100 страниц, чтобы не слетело SEO)
   - папка `assets/` (стили и оптимизированный код)
   - папка `images/` (все фотографии материалов)

2. **Зайдите в панель управления хостингом:**
   - Откройте **Файловый менеджер** (File Manager).
   - Зайдите в корневую папку сайта (обычно она называется `public_html`, `www` или `dom-amk.by`).

3. **Сделайте резервную копию старого сайта (Бэкап):**
   - Создайте внутри новую папку, назовите её `old_site_backup`.
   - Выделите все старые файлы сайта и переместите их в эту папку `old_site_backup`. 
   - *Плюс этого способа:* вы ничего не удаляете насовсем. Если вдруг понадобится какой-то старый текст или фото — они в целости лежат в этой папке.

4. **Загрузите новые файлы:**
   - Скопируйте всё содержимое из папки `dist` прямо в корень `public_html`.
   - Убедитесь, что файл `.htaccess` тоже скопирован (в файловом менеджере хостинга включите галочку «Показывать скрытые файлы», если точки в начале имени не видно).

5. **Готово!**
   Откройте `https://dom-amk.by` в браузере и на смартфоне: сайт откроется мгновенно, с адаптивным дизайном 2026/2027 года, рабочей защищенной формой и автоопределением времени работы склада!
